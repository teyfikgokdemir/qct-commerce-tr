# QCT Commerce — Website-build acquisition execution brief (16 October 2026)

## Commercial objective
**New website design and development** is the primary offer. E-commerce, SEO, automations and ads are secondary/upsell services, not the core homepage search intent. No paid advertising at this stage.

## Existing URLs to strengthen first
- / — lead with *kurumsal web sitesi yapımı*, *profesyonel web tasarım*, *web sitesi kurulumu*; keep project builder and transparent price calculator.
- /web-tasarim/ — primary commercial landing page. Explicitly distinguish new website build, redesign and ongoing maintenance.
- /hizmetler/ — reorder presentation so web design is the first service; do not delete e-commerce or existing indexed services.
- /calismalar/ — link real, permission-cleared case studies to /web-tasarim/ with verifiable project scope.
- Existing /sektorler/ pages — link relevant sector projects to /web-tasarim/ and pricing tool. Do not create doorway city pages.

## Search intent and proposed content
- Transactional: *kurumsal web sitesi yaptırmak*, *web sitesi yapan firma*, *web tasarım fiyatları*, *WordPress web sitesi kurulumu*, *çok dilli web sitesi yapımı*.
- Sector-specific, only where genuine work/examples support it: *oto galeri web sitesi yapımı*, *laboratuvar web sitesi tasarımı*, *ihracat firması web sitesi*.
- Existing pricing content should explain scope, number of pages, CMS, hosting/domain exclusions, revisions, responsive testing and post-launch support. Prices must match the live calculator; do not invent guarantees.
- Each commercial page needs a specific H1, unique title/meta description, useful FAQ, 1–2 contextual links to verified case studies, and a clear **project brief / price estimate** CTA.

## Conversion and trust
Preserve working WhatsApp/form/calculator routes; test that submitted project type and scope reach the correct channel. Do not claim project delivery or client endorsement without evidence. Keep mobile-first design and current premium visual identity.

## Search Console measurement
Track 28-day nonbranded query impressions, clicks, CTR and positions for homepage, /web-tasarim/, sector pages and case studies. Prioritize existing pages ranking 4–20 before creating new ones.

## Acceptance criteria
Homepage service hierarchy visibly prioritizes website builds; no broken existing pricing/CTA flows; old service pages remain accessible; canonical/hreflang/sitemap remain valid; tests/build pass before merge and production release.

## 30-day organic acquisition checklist — 14 November 2026

Baseline for 15 October–11 November 2026: **3,289 organic impressions, 15 clicks and 0.46% CTR** in Search Console. Record the same 28-day comparison window each week for non-brand impressions, clicks, CTR and average position; separately record valid project briefs and qualified leads.

- **Week 1 — publish and measure:** review the PR, deploy only after CI approval, then mark `generate_lead` as a GA4 key event and verify one consented test brief without sending private field values to analytics.
- **Week 2 — improve proven demand:** review the ikas cost article's queries and search-result CTR; change title or answer copy only when the post-release Search Console sample is sufficient. Do not create more location pages while the focused indexation policy is settling.
- **Week 3 — strengthen commercial paths:** inspect internal links from relevant blog, ikas, Shopify, pricing and service pages to the most appropriate commercial destination. Preserve intent-specific anchors and measure project-brief starts and completions.
- **Week 4 — earn external discovery:** prepare only permission-cleared case studies and accurate directory profiles. Prioritize relevant industry or partner listings over bulk links; record the live URL, owner and publication date for every approved placement.

Owner checkpoint each week: non-brand impressions, clicks, CTR, average position, valid project briefs, qualified leads, the ikas article, and the highest-impression commercial pages. No backlink or directory submission, GA4 account change, merge or deployment was performed from this branch.
